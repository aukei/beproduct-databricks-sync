DTC FABRIC → BeProduct Material Master field mapping (Phase 8)
==============================================================
Confirmed live against the DTC "KTB FABRIC" document WIP_ITS_USE view
(view id 6a0ac943fedfa0ca7ff2bf48, 120 dynamicFields, 2026-07-17).

Phase 8a: Pull DTC FABRIC sheets → Delta (dtc_fabric_<customer>).
Phase 8b: Upsert adopted rows → BeProduct Material Master (planned).

Scope / filter
--------------
Only rows where DTC "Adoption (Y/N)" = "Y" are written to Delta.
Sheet-type switch (include_test_sheets widget in pull_fabric_to_delta):
  false (default/production): PROD sheets only — named "<customer> <season> <brand>"
  true  (UAT/dev):            ALL sheets including DEV (" - DEV" suffix) and MILL
                              ("-<MILLCODE>" no-space-dash suffix)

Sheet naming patterns in "KTB FABRIC":
  PROD  "KTB SS28 Blue Bell"               real production sheet (future)
  DEV   "KTB SS28 Blue Bell - DEV"         dev/test master development sheet
  MILL  "KTB SS28 Blue Bell-HUBO"          mill-specific allocation sheet

Sync direction (all DTC → BeProduct for Phase 8b)
--------------------------------------------------
  DTC "LF Material ID"        → BeProduct  lf_material_id   (PRIMARY KEY / match key)
  DTC "Fabric Content"        → BeProduct  Material Description
  DTC "Material Class"        → BeProduct  Material Category
  DTC "Fabric Type"           → BeProduct  Fabric / Material Type
  DTC "Mill Fabric Article #" → BeProduct  Mill Fabric Code
  DTC "Mill Name"             → BeProduct  Mill / Supplier Name
  DTC "KB Fabric Code (SAP Code)" → BeProduct  KB / SAP Fabric Code

Key:
  DTC "ITS_Key"               → staging   its_key     (DTC system row key; not a BP field)
  DTC "Adoption (Y/N)"        → staging   adoption    (filter only; not pushed to BP)
